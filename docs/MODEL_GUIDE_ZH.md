# 算法、参数与阅读说明

## 1. 为什么按周期建模

同周期样本的表格字段通常相近，因此周期表格专家把临床列聚合为一行，估计整体阳性风险，再展开回该周期所有样本。它本身不能充分区分同周期样本，视频排序用来补充这种个体差异。

`groupby(...).first()`是每列首个非缺失值，不一定是原表同一行。周期内字段不一致需要先审计，不能把聚合操作当成数据纠错。

## 2. 表格支路

历史四视图为doctor_soft、doctor_majority、old20_soft、full_soft。全局周期专家用XGBoost，PGT类型专员与全局概率进行验证选择的混合，再通过OOF LogReg门控及历史校正形成教师锚点。完整教师最优快照并非仅由当前`run_multiview.py`一次运行得到。

软比例目标形式为：

```text
target = (positive_count + shrinkage * training_prevalence) / (cycle_size + shrinkage)
```

更新字段残差脚本先应用历史锁定规则，再用Ridge和深度1 XGBoost拟合比例/多数侧logit残差。验证选择头及eta，训练与验证合并后重拟合，再预测测试折。

```text
p_corrected = sigmoid(logit(p_anchor) + eta * 4*p_anchor*(1-p_anchor) * residual)
```

文本支路将7类字段拼接，冻结Qwen3-Embedding-0.6B提取1024维向量。按训练周期拟合StandardScaler，再拟合PLSRegression(n_components=2)。训练行按周期大小重复，以近似样本数加权的周期阳性比例回归。最后：

```text
p_table = 0.975 * base_probability + 0.025 * pls_2
```

这里的2.5%固定系数来自历史选择，不是可训练门控，也没有使用Qwen2.5-VL语言分类。

## 3. 冻结视觉表征

本入口读取旧像素缓存。每阶段有短、长跨度两个16帧视图，优先长视图，缺失时回退短视图。**不能把该实现描述为在这里对完整阶段重新均匀抽帧**。

灰度160×160复制为3通道，插值到384×384，按固定均值和标准差处理。冻结V-JEPA2.1 ViT-B（外部权重）逐阶段编码：

| 张量 | 形状，省略batch轴 |
|---|---|
| 输入有效阶段 | 3 × 16 × 384 × 384 |
| 编码输出重排 | 8 × 24 × 24 × 768 |
| 空间平均池化 | 8 × 3 × 3 × 768 |
| 一个样本四阶段缓存 | 4 × 8 × 9 × 768 |
| 阶段有效标记 | 4 |

空间平均得到时间序列，时间平均得到阶段全局特征，相邻时间格差分形成动态特征。`early`命名指前3阶段，不只是第1阶段。特征拼接mask后，训练折拟合StandardScaler及PCA32 whiten。

同周期内每对正负样本产生`x_pos-x_neg`和反向差分。LogisticRegression(C=0.03, fit_intercept=False, solver=liblinear)学习排序方向。输出是decision_function排序分数，非概率。没有正负混合周期时无法构造监督对。

## 4. 排序小修正

最终候选为已有排序分数加一至两路阶段分数的小权重修正。12个固定候选包含不修正回退项。选择规则要求开发折至少2折提高、至少3折不下降、最差变化不低于−0.015，并惩罚折间波动和权重L1。

已有分数来自历史堆叠，含表格/视频基线成分，因此不能拿其AUC作为严格纯视频分类成绩。

## 5. 数量模型

对大小n的周期，构造n个二分类问题：`I(K >= j)`，j从1至n。输入为表格概率、logit概率、n、n*p、j、j/n、p−j/n和类型编码。标准化与one-hot只拟合训练子集。LogReg使用balanced类别权重，C候选为0.05、0.2、1.0。

先预测生存概率S(j)=P(K>=j)，用最小值累积强制单调，再差分得到P(K)。记录众数K、最大后验、前两名差、归一化熵。这不是简单的`round(n*p)`。

外折f固定后，内折vf的数量模型只用非f且非vf的数据拟合。开发后验用于选解码阈值，再用非f全部周期拟合，预测f。

## 6. 保守Top-K

初始保留表格0.5阈值分类。只有下列条件全部成立才改判：

- 0 < K < n，且K与原表格阳性数不同。
- 阳性数量变化不超过1或2。
- 数量后验及前两名差够大，归一化熵够低。
- 第K名与第K+1名之间的标准化排序间隔够大。

1920种候选门控配置按开发集结果选，至少净增2个正确样本、至少2个内折改善且没有内折下降。没有合格策略时用不可达阈值强制退回表格。

三个容易误读的细节：

1. `max_changes`实际限制阳性**数量差**，并不是任意输入下的逐样本改判数。只有同周期基线类别一致等条件下，两者才等价。
2. `acted`标记整个执行周期，不能用其和当作改判样本数。
3. 改判后的`prob`由名次人工映射成Sigmoid分数。它让0.5阈值与Top-K类别一致，但不是校准概率，不能直接解释为绝对风险。
