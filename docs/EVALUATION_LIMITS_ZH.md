# 历史结果的证据边界

本仓库对应历史1240例外折预测汇总：ACC 0.6741935484，AUC 0.6757920272。本次只注释和发布代码，未新训练或重跑真实数据。

## 本层隔离不等于全链路嵌套

最终入口对每个外折只在其他折上选择权重和解码策略。但它消费已经生成的阶段OOF和表格OOF：开发折的上游模型可能曾使用当前下游外折的标签训练。因此，**对普通OOF再做外折选择，不能自动得到完整嵌套测试**。

完整确认性实现需要：对于每个外折f，重新生成不含f训练信息的内层表格、排序与文本头预测，再用内层预测选门控。所有固定规则和候选集应在未参与报告的开发数据上预先锁定。

## 其他限制

- 文本头与混合权重曾按全量OOF表现探索，不等于独立测试集选择。
- `standardize`使用每个折整批无标签分数统计，是转导式变换，不能直接部署为单样本推理。
- 历史数字化视频键可能有字母前缀丢失或碰撞，inner join会缩小队列。原表格1265例与最终1240例不能无审计地混为一个分母。
- 同周期不跨折不等于同患者多周期不跨折，后者需要患者级关联信息。
- 排序分数含历史融合成分，不能称为独立纯视频。
- Top-K连续分数未校准；ROC-AUC与Pair-AUC也不是同一个指标。
- 反复研究同一数据集产生选择偏差。当前相对表格仅净增4例正确，需要独立队列和预注册配置确认。
- 旧代码保存的`protocol`字符串保持原样以便追溯，其中`strict`不作为本次审计结论。

## 本次检查能证明什么

23个归档Python文件与服务器快照的AST一致，新增注释不改变原运算结构。合成测试验证解码与数量后验的若干局部条件。这不证明完整研究流程无泄漏，也不等于已经复现全部训练结果。
